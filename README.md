# Protocolo Lombricomposta — seguimiento

Página de seguimiento del protocolo de tesis «La lombricomposta como espacio
pedagógico de resignificación de la cultura: una exploración filosófica de la
otredad animal» (Maestría en Filosofía Contemporánea Aplicada).

Documento de trabajo en proceso. El avance se marca con casillas y se guarda
en el navegador con el que se abra la página.

## Publicar con GitHub Desktop

1. Abrir GitHub Desktop → **File → Add local repository** → elegir esta carpeta
   (`github-pages`). Dirá que no es un repositorio y ofrecerá **create a repository**:
   aceptar.
2. Nombre: `protocolo-lombricomposta`. **Create repository**.
3. **Commit to main** (el mensaje puede ser «primera versión»).
4. **Publish repository**. Ahí se elige si queda público o privado.
5. En el navegador, dentro del repositorio: **Settings → Pages** → Source:
   *Deploy from a branch* → Branch `main` / `/ (root)` → **Save**.
6. En dos o tres minutos queda en:
   `https://chipoguerrero-lgtm.github.io/protocolo-lombricomposta/`

## Para actualizarla después

Se reemplaza `index.html` en esta carpeta, y en GitHub Desktop: **Commit to main**
→ **Push origin**. Las casillas marcadas no se pierden, porque viven en el
navegador y no en el archivo.

## Nota

GitHub Pages en un repositorio privado requiere GitHub Pro. En cuenta gratuita,
para que la página funcione el repositorio debe ser público.
